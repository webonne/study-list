## 怎么用过关卡片

过关卡片分三类条件，**全部达标才算过关**：

- **🎯 硬指标**：可量化、可复现。跑一下就知道过没过，不存在"我觉得差不多"。
- **🖥 演示题**：能当着别人的面跑起来。防止"代码能跑但我不知道为什么能跑"。
- **🗣 口试题**：合上电脑，用自己的话讲清楚。防止复制粘贴式通关。

**没过就没过。** 记录卡在哪一条，下周优先补。带着漏洞往前冲的代价，在第三、第五阶段会加倍还回来。
