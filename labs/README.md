# labs

小实验区。一个想法一个目录，命名 `lab-<编号>-<主题>/`，例如 `lab-03-chunk-strategy/`。

允许乱、允许硬编码、允许没有测试。**唯一硬性要求**：每个 lab 目录下有一个 `README.md`，包含：

```markdown
# lab-XX 主题

## 想验证什么
（一句话假设，例如：parent-child 切块能否在长文档上明显优于固定切块）

## 怎么做的
（数据集、变量、对照组）

## 结论
（数字 + 一句话判断。没有结论的实验等于没做）

## 下一步
（这个结论改变了什么决策）
```

三个月后你只会记得结论，不会记得代码。写结论比写代码重要。
